# Placement Prep Java

This repository is a personal space for daily Java-based DSA practice aimed at placement preparation.

The goal is to keep solving problems consistently, maintain notes, and build a strong foundation in arrays, patterns, and core problem-solving techniques.

## Repository Structure

- 00-Notes/ - Short notes, concepts, and important learnings
- 01-Patterns/ - Common coding patterns and practice sets
- 02-Arrays/ - Array problems organized by difficulty
  - Easy/
  - Medium/
  - Hard/

## What This Repo Will Contain

- Daily solved questions
- Java solutions with explanations
- Notes for important concepts
- Practice progress over time

## Suggested Daily Workflow

1. Solve at least one question every day.
2. Write the solution in Java.
3. Add a short explanation of the approach.
4. Commit your work with a clear message.
5. Push to GitHub regularly.

## Suggested Commit Format

- day-01: solved two sum
- day-02: practiced sliding window
- day-03: added array notes

## Example Git Commands

```bash
git add .
git commit -m "day-01: solved two sum"
git push origin main
```

## How to Start with GitHub

If this is your first push, use:

```bash
git init
git branch -M main
git remote add origin <your-repository-url>
git add .
git commit -m "Initial commit"
git push -u origin main
```

## Tips

- Keep your solutions clean and readable.
- Use meaningful file names.
- Review mistakes and note patterns.
- Stay consistent rather than aiming for perfection.

Happy coding and all the best for placements!
